# 상품 사진 넣는 곳

이 폴더에 사진 파일을 넣으면 쇼핑몰 화면에 그 사진이 나옵니다.

## 넣는 방법

1. 아래 표의 **파일 이름** 그대로 사진 이름을 바꿉니다. (예: `ramen-sagol.jpg`)
2. 이 `images` 폴더 안에 넣습니다.
3. 저장하고 GitHub에 올리면 끝입니다.

## 사진 규격

- 형식: **jpg** (확장자를 꼭 `.jpg`로)
- 크기: **가로 800 x 세로 600** 정도를 권합니다 (가로가 조금 더 긴 사진)
- 용량: 한 장당 **300KB 이하**를 권합니다. 너무 크면 화면이 느려집니다.

## 아직 사진을 안 넣었다면

파일이 없으면 인터넷에서 비슷한 사진을 자동으로 가져와 보여줍니다.
어디까지나 **임시 사진**이니, 실제로 판매할 때는 직접 찍은 사진으로 꼭 바꿔주세요.
